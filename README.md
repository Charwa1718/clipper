# Clipper

A modern video sharing platform for discovering and sharing short-form video content.

## Features

- **Home Feed** – Curated video recommendations tailored to your interests
- **Shorts** – Quick, engaging video clips designed for instant enjoyment
- **Library** – Manage and organize your saved content
- **Subscriptions** – Follow creators and get updates on their latest uploads
- **Responsive Design** – Works seamlessly on desktop, tablet, and mobile devices

## Tech Stack

- **Frontend** – HTML5, CSS3, JavaScript
- **Design** – Modern dark theme with gradient accents

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Charwa1718/clipper.git
   ```

2. Open `index.html` in your browser or serve with a local web server:
   ```bash
   python -m http.server 8000
   ```

3. Navigate to `http://localhost:8000` in your browser
